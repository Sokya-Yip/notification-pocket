# 微信赞赏码配置

v1.4.2 起，首页底部“支持作者 · 微信赞赏”和“关于 → 支持作者”都在 App 内显示随包内置的微信赞赏码。长按二维码或点“发送赞赏码到微信”可通过系统分享把原图交给微信；优先使用微信在系统清单中公开导出的发送聊天图片接收组件，避免包名分享同时列出状态、收藏、朋友圈等入口，版本不兼容时回退普通分享。这不是调用隐藏 API，也不模拟微信点击。非导出的私有 Provider 只对该图片提供临时只读授权，不开放其他文件。App 不自动选择联系人、发送或识别，不打开网页，不集成支付 SDK，也不申请互联网权限。此前未验证到实际赞助入口的第三方平台方案已停用，不再配置或猜测替代地址。

## 使用与验收边界

- 同一台手机无需截图：长按二维码或点按钮，在微信分享页自行选择“文件传输助手”并发送，再在聊天中长按已发送图片识别。另一台手机可直接使用微信“扫一扫”。
- 第三方 App 不能调用微信聊天内的长按识别，也不能凭个人赞赏码可靠地直接打开付款确认页；不要使用私有接口、无障碍模拟点击或自动发送来绕过这些步骤。
- 用户应在微信页面自行核对收款人。是否赞赏及金额完全自愿，核心功能没有差异。
- 图片完整性不等于收款能力验收。实际扫码落地页、收款人身份及预设金额仍需作者在微信中确认；不能凭文件哈希推断这些信息。
- 验收只确认能调起微信图片分享页，随后返回；不选择联系人、不实际发送、不测试真实付款。不要把赞赏码上传到第三方解码服务，不收集支付凭据。
- 更换图片时保留原始文件、重新记录 SHA-256，并执行同一套 Release 字节一致性检查。
