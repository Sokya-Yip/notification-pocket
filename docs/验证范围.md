## 已完成的真机验证

设备：HONOR LDY-AN00，MagicOS 11.0.0，Android 17，SDK 37。设备型号只用于说明实测环境，App 不包含该设备的专用规则。

此前同签名验证包已完成：

- 默认长期、24 小时、1 小时三种隐藏时长及恢复；直接核对系统到期时间，不只看 Toast。
- 一次“通知使用权仍在、系统实时监听缺失”的受控恢复；HONOR 自动管理保持不变。
- 首页赞赏按钮与分享按钮的实际 48dp 高度、圆角边界和文字边距。
- 首页赞赏入口到微信公开 `ShareImgUI` 发送聊天图片接收页，随后立即返回；未选择联系人、未发送、未识别二维码、未付款。
- 包名分享曾被 HONOR 系统选择器展开为聊天、状态、收藏、公众号、朋友圈 5 个入口，因此改为显式调用微信公开导出的聊天图片接收组件，失败才回退普通分享。

最终 Release 仅在上述已验证逻辑上调整了首页赞赏按钮的小爱心与暖色外观；这一最后外观调整完成了干净构建和静态资源检查，**尚未再次覆盖安装或声称通过目视验收**。Release 与真机验证包使用不同签名，不能用 Debug 验证结果替代 Release 安装验证。

## 尚未覆盖或需要作者确认

- 首次未授权安装、受限设置帮助和返回续接需要合适的未授权环境；不为凑测试撤销当前有效授权。
- 进程或服务重启、手动重新连接、重试耗尽和 60 秒冷却并非所有组合都做过最终设备回归。
- 最新暖色赞赏入口的小屏滚动、最终目视效果和其他机型兼容性仍需验证。
- 微信收款人、实际扫码落地与金额选项需要作者在微信内核对；图片字节一致不等于这些项目已验证。
- 不保证所有厂商、所有受保护通知都能隐藏或恢复。
- Release 私钥与密码需要作者自行完成至少两份安全加密离线备份并验证恢复。
