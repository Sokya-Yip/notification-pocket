- 本次调试包：versionCode 8、versionName 1.4.3（debug），202323 字节，SHA-256 为 `C7F9DDF24E3639A916E9ED902A98DF68212CBFEAA47205AF829C2E4BB1363B72`。仅用于反馈诊断与云端测试，不公开发布；Release 签名包未改动。
- Debug 自检 Activity（仅 debug 源集，Release 清单中不存在）三项全部通过：授权轨迹 192KB 截断与重置、反馈 Provider 的 UTF-8/替换/拒绝/清空、系统退出记录读取边界。
- 自检曾真实失败一次：达到 192KB 上限后仍有事件被追加。原因是截断时保留的字节数低于上限，仅按文件大小判断会重新允许写入；已改为写入前先检查末尾上限标记，复测通过。这是自检发现并修掉的真实缺陷，不是测试误报。
- 同时修掉本次改动自身引入的启动崩溃：`InsetsController` 在 `setContentView` 之前获取会得到空的 DecorView，导致主页一进入就闪退。现改为先 `setContentView` 再设置系统栏与外观，启动正常。
- 手势导航（`nav_mode=2`，overlay `com.android.internal.systemui.navbar.gestural`）：整屏自上到下采样为同一 `#EEF3F0`（238,243,240），状态栏、正文与小白条区域无分界线；原先 `#FAFCFB` 的浅色导航带消失。

## 尚未覆盖或需要作者确认

- 首次未授权安装、受限设置帮助和返回续接需要合适的未授权环境；不为凑测试撤销当前有效授权。
- 红米 K100 Pro Max“点去授权直接闪退/回桌面”尚未取得设备上的授权轨迹、系统退出记录或 logcat，现象与原因都未确认，因此本版不声称已修复该问题，也不把它推广为 HyperOS 缺少通知使用权。
- 状态栏与导航条适配只在 AOSP Android 14 模拟器上实测；HyperOS、MagicOS 及其他厂商皮肤的浅色图标、手势条对比度和系统栏对比度策略仍需真机确认。
- 手动重新连接、服务单独断开重连、重试耗尽和 60 秒冷却并非所有组合都做过最终设备回归。
- 最新紧凑赞赏入口的小屏滚动、人工目视效果和其他机型兼容性仍需验证。
- 微信收款人、实际扫码落地与金额选项需要作者在微信内核对；图片字节一致不等于这些项目已验证。
- 不保证所有厂商、所有受保护通知都能隐藏或恢复。
- Release 私钥与密码需要作者自行完成至少两份安全加密离线备份并验证恢复。
