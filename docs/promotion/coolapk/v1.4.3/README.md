# 酷安首发素材（v1.4.3）

## 发布内容

- [酷安首发文案](酷安首发文案.md)：包含标题、正文、下载地址以及 v1.4.3 APK 的大小与 SHA-256。
- `00-题图.png`：1600 × 900，16:9；关键文字位于中央裁剪安全区。
- `01-核心功能.png`：说明只隐藏用户选中的状态通知。
- `02-时长选择.png`：说明长期、24 小时和 1 小时三档时长。
- `03-恢复入口.png`：说明可以从“已隐藏”提前恢复。
- `04-隐私权限.png`：说明本机处理和权限边界。

四张配图均为 1080 × 1440。建议顺序：题图 → 核心功能 → 时长选择 → 恢复入口 → 隐私权限。

## 素材边界

这些图片是根据 App 实际界面与配色绘制的**宣传示意图，不是原始设备截图**。通知应用、标题和正文均为通用示例，不包含真实通知、联系人、设备详情或支付信息。

如果平台要求原始应用截图，请另行制作无隐私的实机截图，不要把这些宣传示意图标记为原机截图。

## 重新生成

仓库根目录下的 [`tools/promotion/generate_coolapk.py`](../../../../tools/promotion/generate_coolapk.py) 使用 Pillow 和 Windows 字体目录中的 Noto Sans SC 字体：

```powershell
python tools/promotion/generate_coolapk.py
```

脚本会重新生成 `dist/酷安首发图-v1.4.3/` 中的分发图片与 ZIP，并在通过图片尺寸和重叠检查后，将五张公开图片同步到本目录。该脚本不会读取通知、截图、签名或手机数据。
